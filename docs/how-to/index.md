# How-to guides

Practical recipes for people who already know what they want.

{doc}`use-in-sphinx`
:   Show ledgers in Sphinx and MyST: fenced blocks, directives with options, included files, inline code, line numbers.

{doc}`use-pygmentize`
:   Highlight ledgers on the command line and from Python.

{doc}`register-manually`
:   Register the lexer by hand where entry points are not available.

{doc}`contribute`
:   Set up the development environment, run the checks, and change the lexer.

```{toctree}
:hidden:

use-in-sphinx
use-pygmentize
register-manually
contribute
```
